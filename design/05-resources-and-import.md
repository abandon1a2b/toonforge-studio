# 05 · 素材详情、对比、导入与待整理

所属：[页面功能设计说明](README.md)。状态：待评审设计。

## A-01 素材详情与版本对比

**入口**：任意图片、声音、视频缩略图，搜索结果，镜头引用，审阅问题。

**使用目的**：看清一份素材的内容、归属、版本、来源与使用情况，并完成整理、比较或选用。

### 页面布局

- 顶部：素材名称、分类、所属对象、当前版本、审阅状态。保留来自哪个页面的返回入口。
- 中央主区：大图、音频或视频播放器；下方显示同组版本缩略条与切换入口。
- 右侧信息区：用途、关联对象、标签、说明、来源、技术参数。名称与分类可编辑。
- 底部标签：版本历史、使用记录、生成／处理记录、审阅意见。
- 主要动作：编辑信息、关联对象、比较版本、选用于剧本、指定参考用途、下载原文件、归档。

### 不同媒体的查看方式

| 类型 | 主区功能 | 需要直接看见的信息 |
|---|---|---|
| 图片 | 适应画面、原尺寸、缩放、拖动、透明背景切换；添加问题定位 | 尺寸、用途、是否裁切／派生、所属造型或机位 |
| 音频 | 播放、波形、拖动、圈选、区间循环、试听音量 | 时长、台词／声音描述、角色或用途、实际选取范围 |
| 视频 | 播放、逐帧、时间码、区间循环、声音开关 | 比例、尺寸、帧率、时长、对应镜头／连续片段 |

试听音量仅作用于当前预览；它与剧本使用音量分开。音频文件不支持浏览器直放时，允许生成试听副本，清楚标明原文件格式并保留原文件下载。

### 归属与分类

- 区分主要归属和附加关联：一张博士服装图主要归属某造型，同时可关联某篇剧本；派生裁切仍能回到原图。
- 分类选择符合当前归属，例如角色设定表、局部参考、表情、动作、声源、台词、场景机位、分镜、音效等。
- 分类说明使用面向人的名称；提供已有标签选择与新标签输入。
- 更改归属前列出既有使用影响；不能通过移动归属使历史剧本失去原来的引用。

### 版本历史与比较

版本项显示内容预览、修订说明、时间、来源、审阅状态和在哪些剧本选用。新版本默认候选，旧版本仍可查看。

比较可从同组版本中选两项，也可手动挑选相关素材：

- 图片：并排与叠加切换，联动缩放／拖动；可临时框选眼睛、配饰等区域查看。
- 音频：A/B切换、相同台词提示、对齐试听区间，播放一个时暂停另一个；支持不同起点，避免前置静音影响比较。
- 视频：并排或同步播放，允许标记各自对齐点，对比动作、机位与连接处。
- 不同媒体类型不能进入同一种比较模式，给出可理解提示。

比较不会替换当前选用。用户明确点击“用于本篇”后才打开选择流程。

### 选用与指定参考

“设为角色主参考”“设为造型代表图”“设为列表封面”“选用于剧本”分别提供入口，说明作用范围。

选用于剧本时：选择目标剧本与具体用途 → 查看现用版本 → 展示会受影响的镜头 → 明确替换范围 → 保存结果。角色、造型、场景和声音提供符合对象的用途选项，不让用户输入内部槽位编码。

候选、通过、需修改为审阅信息；“被本篇选用”是使用信息。需修改版本禁止新增选用；历史已有使用仍保留并提示需要检查。

### 来源与制作记录

来源区支持网页、作者、附件、许可说明、署名要求和采集说明。缺少来源时显示待补，不能自动编造。

生成／处理记录按实际可得内容显示模型、提示词、参数、输入参考、任务标识、裁切范围或处理说明。没记录就显示未记录；密钥和认证信息不进入页面、导出或日志。

### 异常处理

文件缺失时保留资料与引用，提供重新定位；定位后先核对是否同一内容。预览失败可下载原文件并重建预览。选用发生并发变化时提示新状态，不覆盖另一窗口选择。

**验收示例**：用户比较两个博士设定表的眼睛／眼罩与面部细节，记录具体位置的意见；选择新图只更新指定剧本，旧剧本仍可找到原选用。

## A-02 导入与待整理

**入口**：全局导入、角色／造型／场景内“添加资源”、左侧“待整理”。同一页面提供“新增导入”和“待整理”两种视图。

**使用目的**：允许先收集文件，再分批整理；批量素材可以一次建立合理归属。

### 新增导入：三步流程

**第一步，选择内容。** 拖入文件、选择文件或文件夹，也可登记项目内已有文件。显示文件预览、名称、格式、时长／尺寸；不支持的文件列在单独区域，允许继续处理支持项。

**第二步，整理与关联。** 左侧文件列表，中间预览，右侧表单。支持多选后批量指定：

- 所属角色／造型、场景／机位、剧本／镜头或公共素材对象。
- 素材用途、名称、标签、来源、备注。
- 作为新素材，或作为现有素材的新版本；后一项必须明确选择目标。
- 代表图、参考图等用途可稍后设置，导入本身不自动通过审阅。

**第三步，确认与完成。** 按归属分组预览即将建立的对象、文件与关联；显示潜在重复、缺少归属和失败项。完成后显示数量及“进入对应对象”“继续整理”“查看失败项”。

### 批量操作细节

- 从博士某造型内进入时预填该造型；每个文件仍可单独改分类。
- 多选值不一致显示“多个值”，不显示一个误导性的统一值。新增标签默认追加；替换标签有单独动作。
- 允许新建角色、造型或公共对象，使用简短表单；复杂资料可导入后补充。
- 导入一张分镜合集时先关联剧本和覆盖镜号；不强制立即拆格，也不把拆格当成验收。
- 支持“暂不整理”：保存到待整理区域；其后可以逐批完善。

### 重复内容

完全相同内容提示已有条目与归属，可复用已有文件并新增关联；不自动覆盖、删除或合并对象。名称相同而内容不同提示可能新版本，要求明确选择。相似图片如有提示，只能作为人工检查线索。

### 待整理视图

显示未归属、未分类、来源待补、外部新发现等筛选。文件可网格预览或列表查看，显示发现位置和时间。选中一批后执行同样的关联整理操作，也可暂时忽略某目录或条目。

扫描发现外部资料变更时，进入“变更比较”子区，显示已维护内容、外部内容和受影响对象。明确导入才建立修订；新媒体候选不自动改变原选用。

### 失败与中断

已完成的成功项保留，失败项可以重试；重复点击不反复建立同一批条目。取消或关闭前保留导入整理草稿。没有完成归属的文件不能伪装成已有正式角色素材。

**验收示例**：拖入博士的20张图与4条声音，批量指定角色、分批指定服装／表情／声源，其中2张待确认的图留在待整理；再次打开能继续处理。
