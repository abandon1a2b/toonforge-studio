# Toonforge Library 页面功能设计说明（文字稿）

版本：0.1 · 日期：2026-10-18 · 状态：待用户评审。

本文描述期望中的产品页面，不表示这些功能已经实现，也不作为自动开始开发的授权。现有程序、旧设计稿和原始素材均保留；本轮只整理页面设计。

## 一、产品要解决的事情

用户可以持续维护角色身份、服装、场景和公共素材，在具体剧本中选择适用版本，并从任意镜头追溯实际使用的画面和声音。找素材、补资料、换造型、审阅和再次复用，都应有明确入口。

页面设计以以下操作作为验收主线：

1. 导入博士的一批图片和声音，整理到角色与具体造型。
2. 维护博士的外观、身高、身份锚点，查找其表情、动作与音色。
3. 为一篇剧本选择博士、散兵、木偶、派蒙和旁白，以及各自的造型与声音。
4. 配置办公室布局和本篇人物座位，检查连续镜头。
5. 比较候选原画、配音和视频，记录意见，固定本篇选用。
6. 下一篇复用已有角色和场景，并保留此前的引用和验收记录。

上述角色仅作操作示例，不增加人物设定，也不变更当前选角。

## 四、统一对象含义

| 名称 | 用户理解 | 示例 |
|---|---|---|
| 角色 | 持续维护的身份与设定 | 博士 |
| 造型 | 隶属该角色的一套服装及外观表达 | 日常白大褂、动画简化版 |
| 场景 | 可复用地点及空间规则 | 一排三人直长桌办公室 |
| 公共素材对象 | 可反复复用的道具、声音或风格参考 | 钢笔、写字声、画风参考集 |
| 素材 | 一份可查看或试听的具体文件 | 一张设定表、一条配音、一段视频 |
| 版本 | 同一设定或素材的某次明确修订 | 原画v2、对白默认版 |
| 剧本使用配置 | 本篇选择的角色造型、音色、空间与文件版本 | 本篇木偶穿哪套、坐哪里 |
| 镜头／连续片段 | 演出单元及需要共同制作的连续镜头组 | 014–015连续拍桌动作 |

角色标签、造型标签、素材标签各自有归属。个人收藏分组不改变素材归属；本篇的人物职业、座位、服装选择属于剧本使用配置。

## 五、共同交互规则

1. 主要对象使用独立详情页，可复制链接、刷新和返回；轻量选择或编辑使用抽屉／弹窗，避免多层弹窗套用。
2. 角色、场景、剧本都有固定总览与分类标签页，进入具体素材后仍能看清归属及返回入口。
3. 列表筛选、滚动位置、查看模式在返回时保留；大量条目分页或分段加载，不一次展示所有历史文件。
4. 资料、选用与验收分别表达：有资料不代表有设定图，有素材不代表已通过，有本篇选用不代表全局正式参考。
5. 未知资料显示“待确认”。制作暂定身高明确标记依据；声音专用角色可以没有图像资源。
6. 更新共享素材时展示使用影响，本篇既有选用保持固定，由用户决定迁移。
7. 保存资料、选用、归档后给出具体结果；失败保留输入，说明如何继续。
8. 对有修改内容的编辑页，离开时提供保存草稿、放弃本次修改、继续编辑；不丢失未保存内容。
9. 图片、声音、视频使用相应预览方式。文件缺失时保留资料及引用记录，并提供重新定位入口。
10. 页面中只有明确完成的用户动作才改变状态。导入、扫描、生成、导出都不自动构成人工验收。

## 六、建议评审与实现顺序

先评审 C-01～C-04 和 A-01～A-02，确认角色与素材的维护手感；随后评审场景、公共素材和剧本的复用；最后补齐审阅、标签与数据管理。

首轮交互样稿至少贯通“导入 → 角色资料 → 造型资源 → 剧本选用 → 镜头引用”。每一环都使用相互关联的示例，避免只展示互不相连的页面。

这份文档不预设必须一次实现所有页面。确认功能与布局后，再划分开发批次、技术方案和验收用例。
