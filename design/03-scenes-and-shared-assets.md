# 03 · 场景与公共素材

所属：[页面功能设计说明](README.md)。状态：待评审设计。

## S-01 场景列表

**入口**：左侧“场景”；剧本选择场景时复用相同列表与筛选。

**使用目的**：找到可复用的地点，了解它已有的空间资料、机位和变体。

### 页面布局

- 标题区：场景数量、新建场景、导入场景素材。
- 左侧筛选：室内／室外、地点用途、世界观／作品、画风、标签、可用状态。
- 顶部工具栏：名称搜索、网格／列表、排序、包含归档。
- 卡片：指定封面、场景名称、简述、主要标签、布局图／机位／变体数量、相关剧本数量。

### 操作与状态

点击进入S-02；卡片菜单支持编辑、加入分组、指定封面、归档。布局尚未建立时显示“空间布局待补”，用户仍可先存放场景参考。参考场景与制作场景有标识，不能把一张氛围图当成已完成的空间设计。

**验收示例**：搜索“办公室”，能区分直长桌版、旧L形方案以及纯风格参考；默认视图优先展示当前使用方案，旧方案可检索。

## S-02 场景详情

**入口**：场景卡片、镜头场景引用、剧本场景安排、搜索。

**使用目的**：明确空间规则，找到不同角度的参考，并检查制作中有没有混用空间版本。

### 固定区域

顶部为名称、封面、说明、地点类型、标签与资料修订号。操作有编辑资料、添加资源、建立变体、用于剧本、导出参考。

### 标签页

| 标签页 | 内容和操作 |
|---|---|
| 总览 | 场景用途、视觉方向、主要区域、当前主参考、待补资料 |
| 空间布局 | 平面图、朝向、门窗、固定家具、走道和区域锚点。图上编号与文字条目对应 |
| 机位参考 | 按机位展示朝向、景别、代表图、可见空间锚点。查看反打、相邻机位及使用镜头 |
| 陈设与道具 | 固定陈设和可移动道具分组。关联公共道具；记录默认位置和可移动范围 |
| 场景变体 | 白天／夜晚、灯光、天气、特殊布置等。查看继承的布局及明确变化 |
| 环境声音 | 关联环境底噪与区域声音，提供区间试听；本篇使用时长在剧本中配置 |
| 全部资源 | 平面图、空间母图、机位图、细节、氛围参考分类查看 |
| 使用与修订 | 本篇引用的场景版本、镜头清单、历史布局、更新影响 |

### 空间与人物的关系

共享场景维护“左席、中席、右席、茶区”等空间位置；具体哪个角色坐在哪个位置，在T-02本篇场景安排中指定。镜头使用两者组合。用户能从“木偶的位置不一致”回查本篇座位安排，而不改写所有剧本的场景。

### 机位参考的操作

用户添加一张参考图，选择已有机位或新建机位，填写朝向、景别和观察说明。与已有平面图一致性由人工审阅记录；系统显示待核对项，不因图片导入成功而表示空间已通过。

### 关键边界

- 色调变化与家具结构变化分别标识。把L形桌改成长桌属于布局修订，显示受影响的机位与镜头。
- 场景变体可以继续引用相同布局；修改公共布局时先显示影响，不自动替换各变体和剧本。
- 场景图片中出现角色，只说明该图含人物；是否是纯场景母图由分类明确表达。

**验收示例**：从办公室平面图看到三个座位，再从正面机位找到对应参考图；进入本篇后看到博士、散兵、木偶的位置映射，历史L形方案不混入当前参考包。

## S-03 新建／编辑场景

**入口**：场景列表新建、场景详情编辑。

### 表单区域

1. 基础：名称必填，说明、所属地点、场景用途、室内／室外、作品／世界观、标签。
2. 空间：主要区域、朝向、门窗、家具、走道、不可移动锚点；重复条目可添加、排序。
3. 视觉：配色、背景细节程度、光照方向、可参考的画风对象。
4. 资源：封面、布局图、空间母图、机位参考。资料可先建立，图像后补。
5. 连续性：固定关系、允许变动的陈设、镜头中应避免的情况。

保存有修改摘要。若调整固定锚点，列出引用该布局的机位、变体、剧本和镜头，提供“保存新修订，既有使用保持”及后续迁移入口。表单离开、并发冲突和失败保留规则沿用全局设计。

**验收示例**：用户不编辑JSON即可补充“白板在北墙、画像在白板左侧”，保存后能在场景详情和本篇引用中找到这两条约束。

## L-01 公共素材列表

**入口**：左侧“公共素材”；场景选道具、剧本选声音时也可打开相应类型的选择视图。

**使用目的**：管理可跨角色、跨剧本复用的道具、声音、特效和风格参考。

### 类型与显示

- 类型栏：道具、音效、环境声、音乐、画风参考、特效及其他。
- 先显示有名称和说明的公共素材对象，再进入其具体文件版本。尚未归类的文件进入待整理。
- 图片对象用代表图；声音用名称、用途、时长与试听；风格参考用多图封面。
- 筛选随类型变化：音乐显示情绪、节奏、乐器等；音效显示动作与材质；道具显示使用场景。
- 通用筛选保留标签、来源／许可完整度、状态、分组、使用剧本。

### 操作

新建对象、导入已有文件、批量标签、分组、归档。选择声音时先区间试听，再添加到剧本声音页；选择道具时先查看结构与比例说明，再关联场景或镜头。

**验收示例**：在音乐里筛选“欢快、轻松”，试听15秒候选；在音效里找“钢笔写字”，看到原始时长和可用片段，而不是直接混入整片。

## L-02 公共素材对象详情

**入口**：公共素材对象卡片、场景道具、镜头声音引用。

### 共同区域

名称、类型、封面／试听、用途、标签、来源、代表版本、全部版本、使用记录。提供编辑说明、添加文件、用于剧本／场景、归档。

### 按类型补充

| 类型 | 专属内容 |
|---|---|
| 道具 | 尺寸及依据、颜色、正反面、开合或使用状态、结构细节、与角色的比例 |
| 音效 | 动作、材质、背景噪声、原始时长、人工整理的可用片段及试听 |
| 环境声 | 地点、时间、氛围、循环适用性、可用片段 |
| 音乐 | 情绪、节奏、乐器、可用于哪些叙事段落；未知BPM不伪填 |
| 画风参考 | 参考图组、线条、上色、阴影、背景密度、明确的取舍说明及来源 |
| 特效 | 适用场景、透明背景／叠加方式、画面尺寸、示例预览 |

整理可用片段只记录起止点与说明；若实际导出新文件，则作为派生素材保存。每篇剧本使用时的音量、时长、淡入淡出单独维护，不更改公共源文件。

**验收示例**：同一条写字声音源在两篇剧本中分别使用不同片段和音量，两篇的使用配置互不影响，且都能回到同一个声音对象。
