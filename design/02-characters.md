# 02 · 角色与服装造型

所属：[页面功能设计说明](README.md)。状态：待评审设计。

## C-01 角色列表

**入口**：左侧“角色”；从选择角色控件进入时使用相同筛选方式，并显示“选择用于哪篇剧本”。

**使用目的**：从持续增长的角色库里找到人，判断已有资料和素材是否够用。

### 页面布局与内容

- 标题区：角色、角色数量、新建角色、导入资料。
- 左侧：全部角色、我固定的分组；作品、阵营、角色用途、标签筛选。
- 顶部工具栏：名称／别名搜索、排序、网格／列表切换、显示归档开关。
- 主区：角色卡片。卡片显示用户指定头像、姓名、作品、少量主要标签，以及设定图／造型／声音的可用数量。
- 列表模式增加身高及依据状态、最近维护时间、资料待补项，支持选择显示列。

### 主要操作

- 点击卡片进入角色详情；卡片菜单提供编辑、加入分组、设置封面、归档。
- 新建角色进入C-03；导入资料进入A-02，并预选“角色资料或角色素材”。
- 标签可点击形成筛选；“新增标签”支持选择已有标签和输入新标签，提示相似名称，减少重复。
- 多选角色后可批量加标签、加入分组或归档。归档前显示仍在使用的剧本数量。
- 封面与头像分别指定；六格设定表保留在资源分类中，不强制作为小卡片封面。

### 状态

无头像使用姓名占位；声音专用角色显示“声音角色”，不标成错误。无素材显示“资料已建立，尚未添加素材”。筛选无结果时保留条件并提供清除。

**验收示例**：选择“愚人众”和“声音已准备”后找到角色；清除筛选能恢复所有角色，旧角色仍保留，但不会因此被加入当前剧本。

## C-02 角色详情

**入口**：角色卡片、搜索、剧本选角、素材归属。

**使用目的**：以一个角色为中心，看设定、找素材、管理造型与声音、了解使用情况。

### 固定区域

顶部显示头像、姓名、别名、作品、主要标签、资料修订号。右侧有编辑资料、添加资源、加入分组、导出、更多操作。角色身份始终保留在页面顶部，切换分类后不丢失。

### 标签页内容

| 标签页 | 页面内容与操作 |
|---|---|
| 总览 | 简介、关键身份锚点、身高及状态、常用造型、明确指定的主参考图、常用音色、待补资料。点击卡片进入对应分类 |
| 人物资料 | 基础身份、原作资料、性格、关系、物理信息、依据。按分区编辑；来源和制作提案分别标识 |
| 外观设定 | 发型、眼睛、体型、肤色、配饰、禁止随意改变的特征。文字与对应局部参考图并排查看 |
| 服装造型 | 该角色的造型卡片，按日常／职业／特殊场合、自定义标签筛选；新增造型进入C-04 |
| 表情与动作 | 表情、口型、手势、站姿、动作参考分区；支持按造型、情绪、用途、状态筛选 |
| 声音 | 声源、整理后的样本、克隆音色、试听样本、实际台词，详见下节 |
| 全部资源 | 该角色及其造型的素材；按归属层级、用途、媒体类型、审阅状态筛选，默认折叠历史 |
| 使用记录 | 引用该角色的剧本、造型、镜头和版本；可跳回具体位置，查看更换共享设定的影响 |

### 声音标签页

上方为“音色档案”，下方为“相关声音资源”，二者有明确层次。

- 音色卡：名称、服务／模型、远端音色标识、语言、取样来源、创建时间、可用状态及关联试听。仅登记标识，不显示密钥。
- 声源区：原始音频、整理后样本分开；显示时长、说话内容、来源、噪声／背景声备注。
- 试听区：固定测试台词及多个声音候选，可做A/B；指明默认参数或具体演出参数，避免仅靠文件名辨认。
- 实际配音区：按剧本、台词、版本筛选，不把所有台词无区分铺满。
- 一个角色可维护多个音色；剧本明确选择其中一个。选择“常用音色”不会替换已有剧本声音。
- 音色过期或远端不可用时保留历史文件与记录。只有已有试听文件才能播放，不显示空播放器。

### 主要操作与边界

“加入剧本”打开选择抽屉：选择剧本、角色用途、造型、音色，列出缺项后保存。编辑共享角色资料时提示哪些剧本引用旧版；不自动迁移。角色全局人物资料中的性格、职业等与本篇改编设定分别保存。

**验收示例**：打开博士，无需猜文件夹即可依次看到外观锚点、日常造型、原始声源、Qwen试听和已经使用他的剧本。

## C-03 新建／编辑角色

**入口**：角色列表新建、角色详情编辑。使用独立编辑页或宽抽屉，长表单有分区导航。

### 表单分区

| 分区 | 字段与规则 |
|---|---|
| 基础身份 | 名称必填；别名、作品、阵营、简介、角色类型可选。稳定标识自动建立，作为高级信息查看 |
| 物理信息 | 身高cm、测量口径、状态、来源；年龄、体重、体型、头身比等按需填，未知可空。实际身高与鞋子／发型／头饰增高分别维护 |
| 外观 | 头发、眼睛、脸部特征、肤色、体型、配饰；每项可添加局部参考图 |
| 身份锚点 | 可排序的短条目；哪些特征必须稳定，哪些允许简化 |
| 性格与表演 | 性格、常见情绪、表达习惯、允许夸张范围；与某篇剧本特有的演出要求区分 |
| 来源 | 添加网页、用户附件、原作记录等；记录类型和说明，可关联到某个字段 |
| 整理 | 标签、分组、头像、封面 |

### 保存行为

- 新建时只要求名称；身高未知写为待确认，不能默认数值。填写数值时要求明确状态和依据。
- 名称相近或别名重合时提示潜在重复，提供查看已有角色；不自动合并。
- 保存前显示字段校验错误并定位到分区；保存成功后返回详情，给出修订说明。
- 编辑不影响已有媒体版本；资料修订可填写原因，历史中能查看字段差异。
- 另一窗口已修改时显示冲突字段和双方内容，允许合并；本次输入保留。
- 普通操作无需编辑JSON。高级导入仅作为补充入口，不替代字段表单。

**验收示例**：给身高填写制作暂定值及依据后，列表与详情显示“制作暂定”；清空数值变为待确认，不能显示0cm或1.0。

## C-04 服装造型详情

**入口**：角色的造型卡片、剧本的已选造型、搜索。

**使用目的**：把一套造型的文字规则、参考图、细节和使用记录维护在一起。

### 页面布局

- 顶部：所属角色、造型名称、代表图、标签、造型状态；提供编辑、添加素材、选用于剧本。
- 总览：服装说明、适用场景、与基础造型的区别、身份保留要点。
- 设定图：六格设定表、正面、侧面、背面、45度等按用途分区；缺少哪类直观显示。
- 细节：配饰、鞋子、图案、非对称结构、色板；可把图与对应说明关联。
- 表演参考：该服装下的表情、动作、口型；不把其他服装的动作默认视为本造型素材。
- 版本与使用：候选比较、主参考版本、本篇选用记录、引用镜头。

### 新建／编辑造型

填写造型名称、类别、适用场合、服装组成、配饰、允许简化的细节、标签。必须归属一个角色。可以“基于已有造型建立新造型”，保留来源关系；复制后独立维护，既有剧本引用保持不变。

原作造型、现代日常改编、动画简化表达有明确标识。必要时维护造型之间的关联，不仅靠“v1/v2”文件名区分。

### 关键行为

- 指定主参考图只影响此造型的默认展示；本篇实际使用版本单独选定。
- 新修订出现后，旧版仍可查看和被旧剧本引用。
- 归档前展示使用影响；本篇仍在使用时不删除对应关系。

**验收示例**：用户能给博士增加年轻日常服装，完整保留原白大褂造型，并让不同剧本分别使用这两套服装。
